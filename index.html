Panduan approval webhook

  2. Node Wait (On Webhook Call): tunggu webhook resume dari Diptera.
  3. Approve / Deny di Diptera: server memanggil resumeUrl dengan decision, approved, reason, dan decidedBy.
  4. Node IF / Switch: cek {{ $json.body.decision === 'approve' }} untuk melanjutkan aksi.
